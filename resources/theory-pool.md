## Instructional Design Models

| Theory | Core Principle | Use When |
|---|---|---|
| ADDIE | Analyze → Design → Develop → Implement → Evaluate | Structured, iterative course development |
| SAM (Successive Approximation) | Rapid prototyping with iterative feedback loops | Agile ID; short timelines |
| Merrill's First Principles | Activate prior knowledge, demonstrate, apply, integrate | Any performance-focused instruction |
| Component Display Theory | Match content type (concept/fact/procedure/principle) to display mode | Precision content design |
| Dick & Carey | Systematic, goal-driven instructional design | Complex, high-stakes training |
| Kemp Model | Flexible, non-linear design addressing 9 elements | Multi-format or blended learning |
| Rapid Prototyping | Build-test-revise cycles | SME-heavy or fast-turnaround projects |

## Theory Selection Rules (from ID system)

**Step 1 — Context Analysis:**
Evaluate: nature of task (concept/skill/decision), complexity (linear vs ill-structured), learner type, duration, transfer expectation.

**Step 2 — Evaluate at least 4–6 theories**

**Step 3 — Produce Theory Consideration Report:**
- Selected theories with justification
- Rejected theories with reason
- Must reject at least 2
- Must include at least one advanced theory

**Step 4 — Apply only selected theories. Never use rejected theories in design decisions.**

**Anti-patterns:**
- Never default to fixed theory-to-topic mappings
- Never use a theory without showing its application in design decisions
- Never skip the rejection step
